Creative Pear Translate AI - Plan de ChatGPT (experimental)

1. Extrae los archivos en una carpeta privada de tu ordenador.
2. Windows: abre Conectar-ChatGPT.cmd (Node.js 22 o posterior).
   macOS/Linux: node cptai-companion.cjs --launch
3. La primera vez autoriza tu cuenta en la pagina oficial de OpenAI.
   Dispones de 15 minutos. No compartas codigos ni contrasenas.
4. El asistente queda en segundo plano y puedes cerrar la ventana.
   En WordPress elige ChatGPT - Mi plan, consulta los modelos y guarda.

SESION PROTEGIDA (desde 1.7.0)
La sesion se guarda localmente y se recupera al reabrir el asistente.
En Windows se cifra con DPAPI para tu usuario del sistema. En macOS/Linux
se usan archivos privados con permisos 0600 y directorio 0700.
Los archivos se escriben de forma atomica. Las renovaciones se serializan
y guardan juntas las credenciales nuevas. Nunca se envian a WordPress,
al navegador, al repositorio ni a los registros.

Cerrar esta ventana, cerrar Codex o actualizar el plugin no cierra la
sesion del asistente en segundo plano. Si reinicias el ordenador, vuelve
a abrir Conectar-ChatGPT.cmd: recuperara la sesion sin autorizar de nuevo,
salvo que OpenAI la haya revocado o haya caducado definitivamente.
El ordenador debe estar encendido y el asistente activo para traducir.
No se instala un servicio ni se modifica el inicio automatico del equipo.

DETENER O CERRAR SESION
Detener-asistente.cmd pausa esta web y conserva su sesion protegida.
Cerrar-sesion-ChatGPT.cmd solicita la revocacion y elimina la sesion local.
En macOS/Linux: node cptai-companion.cjs --stop o --logout.
Sin --launch, Ctrl+C detiene el proceso conservando la sesion.
Si la revocacion remota no se confirma, desconecta la aplicacion en los
ajustes de ChatGPT. Cada web mantiene su propia vinculacion.

ACTUALIZACIONES
Actualizar el plugin conserva la vinculacion y el modelo elegidos.
Los cortes de red y el mantenimiento de WordPress se reintentan sin
revocar la sesion. Una respuesta ya generada no se vuelve a traducir.
Para cambiar solo los archivos del asistente usa "Actualizar asistente"
en WordPress. Deten el asistente, reemplaza los archivos y vuelve a abrirlo.
Conserva cptai-connection.json: el ZIP de actualizacion no lo incluye.
"Descargar asistente y vincular" crea una vinculacion nueva y sustituye
la anterior. No lo uses para una actualizacion rutinaria.

No compartas cptai-connection.json: permite recoger y responder a los
trabajos de traduccion de esa web. Guarda el ZIP de vinculacion en privado.
Desvincular en WordPress cancela el acceso a esa web; no revoca por si
solo la autorizacion de OpenAI. Usa Cerrar-sesion-ChatGPT.cmd para eso.

Las APIs opcionales de OpenAI y Claude se conservan. Nunca se cambia
automaticamente a una API de pago. El plan comparte sus limites y creditos.
No se leen sesiones de Codex ni de otras aplicaciones.
